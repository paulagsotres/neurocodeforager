summary:
This paper shows that the four major hippocampal GABAergic interneuron families (Pvalb, Sst, Vip, Id2) can be reliably identified in large-scale extracellular recordings using only physiological features — spike width, firing irregularity, ACG rise time, waveform asymmetry, theta modulation — trained on opto-tagged ground-truth data, and that these families cooperate to differentially shape the spatial features (stability, selectivity, generalization, place-field amplitude) of CA1 pyramidal place cells.

abstract_long:
Valero et al. combined silicon probe recordings with optogenetic identification (ChR2 in Pvalb, Sst, Vip, Id2, and CaMK2α lines) to collect ground-truth physiological fingerprints for all major interneuron families in freely moving mice, across both the hippocampus and neocortex. A decision tree classifier trained on six physiological features (CV2, ACG rise time, spike width, anatomical location, waveform asymmetry, firing rate) achieved >89% accuracy per family in 10-fold cross-validation and was then applied to large-scale, unlabeled recordings (5276 CA1 units from 155 sessions, 30 mice), whose predicted family fractions matched gene-expression-based fractions. The study then examined how the four interneuron families cooperatively shape pyramidal place cell spatial coding: Pvalb suppressed the first half of place fields, while Sst and Id2 suppressed the second half; Vip disinhibited CaMK2α neurons via Sst suppression and increased place-field amplitude. CEBRA-based decoding showed that interneurons alone (at matched cell counts) decode spatial position as accurately as pyramidal cells, and leaving out any single family increased decoding error. The physiological fingerprinting strategy is paradigm-independent and applicable to datasets from different labs and species.

tutorial_intro:
The core reusable output of this paper is the interneuron family classifier in <a href="https://github.com/valegarman/HippoCookBook/tree/main/analysis/cell_type_classification">HippoCookBook/analysis/cell_type_classification</a>. Given any sorted CA1 hippocampal dataset, it assigns each unit to one of five families: Pvalb, Sst, Id2, Vip, or CaMK2α. Important constraints: (1) the classifier reads the <code>cell_metrics</code> struct produced by CellExplorer — this is a hard dependency, CellExplorer must be run first; (2) the full classifier only works for hippocampal CA1 neurons, as the CA1-specific LFP features (theta modulation, SPW-R response, gamma phase locking) depend on hippocampal oscillatory landmarks that don't exist in neocortex.

tutorial_steps:
Run CellExplorer (<a href="https://github.com/petersenpeter/CellExplorer">petersenpeter/CellExplorer</a>) on your KiloSort-sorted CA1 data. CellExplorer outputs a <code>cell_metrics</code> struct (saved as <code>session.cell_metrics.cellinfo.mat</code>) containing the waveform and spike-train features the classifier needs: <code>cell_metrics.waveforms</code> (spike width, asymmetry), <code>cell_metrics.acg</code> (autocorrelogram and rise time), <code>cell_metrics.firingRate</code>, <code>cell_metrics.cv2</code>, and <code>cell_metrics.general.chanCoords</code> (anatomical location). This struct is the required input format.
Run the LFP feature extraction functions in HippoCookBook to add CA1-specific features to <code>cell_metrics</code>: theta phase modulation (<code>computePhaseModulation.m</code>), SPW-R response (<code>rippleMasterDetector.m</code> + PSTH), and slow/mid/fast gamma phase preferences. These are computed from the raw LFP alongside the spike data and appended to <code>cell_metrics</code> before classification.
Call the classifier: load the pretrained model from <code>cell_type_classification/</code> and pass your <code>cell_metrics</code> struct. The classifier returns a predicted family label (Pvalb / Sst / Id2 / Vip / CaMK2α) and a confidence score per unit. A classification cutoff of ≥95% confidence per family is recommended (as used in the paper).

tutorial_output:
A per-unit table of predicted interneuron family labels and confidence scores, ready to use as cell-type annotations for any downstream analysis (place fields, functional coupling, population decoding). The classifier achieves >89% accuracy per family (>97% for CA1 with LFP features) in 10-fold cross-validation against opto-tagged ground truth.
