summary:
BRAINCELL extends the NEURON simulation environment to enable biophysically realistic modelling of neurons and glia with stochastically generated nanoscale structures (dendritic spines, astrocytic processes) and a dynamic, interactive extracellular milieu that tracks spatiotemporal ion and signalling-molecule concentrations — revealing outcomes that differ substantially from conventional spineless, static-extracellular models.

abstract_long:
Biophysical compartmental models have largely lacked two features critical for realistic simulation: nanoscale structures such as dendritic spines and thin astrocytic processes (too numerous and variable to reconstruct individually), and a dynamic extracellular environment (traditionally treated as static). BRAINCELL addresses both by (1) stochastically generating populations of nanoscale morphological elements constrained by empirical statistics — for example, populating CA1 pyramidal dendrites with thousands of spines whose head radius, neck length, and neck diameter match STED microscopy measurements — and (2) implementing a dynamic extracellular milieu that tracks spatiotemporal ion (K+, Na+) and neurotransmitter (GABA, glutamate, ATP) concentrations inside and outside cells using mesh-free Inside-Out diffusion calculators and NEURON RxD. Four cell types are supported: neurons, astrocytes, myelinated axon oligodendrocyte units, and microglia. Demonstrated results include: spine populations expanding the synaptic input-output dynamic range from 0–40 Hz to 5–90 Hz; extracellular K+ hotspots boosting dendritic excitability several-fold at low input frequencies; individual interneurons generating extracellular GABA waves that reduce pyramidal cell firing by ~46% via tonic inhibition; Kir4.1-expressing astrocytes suppressing extracellular K+ accumulation and reducing neuronal firing by ~15%; and myelinated axon spike propagation failing when oligodendrocyte Kir4.1 channels are removed. The platform includes a built-in AI agent (Claude/Anthropic) for natural-language modification of MOD, HOC, and Python files without command-line interaction.

tutorial_intro:
BRAINCELL is downloaded from <a href="https://www.neuroalgebra.net">neuroalgebra.net</a> (free registration required) and installs as a desktop application on Windows, macOS, and Linux. It runs entirely through a point-and-click GUI built on top of NEURON — no command-line or coding required for standard workflows. Users import cell morphologies from standard databases (NeuroMorpho.org, Allen Institute, BlueBrain, etc.) in SWC, NeuroML, or HOC format, then use GUI menus to populate cells with nanoscale structures, configure synaptic inputs, set extracellular parameters, and run and visualize simulations. A headless export mode is available for batch runs on HPC clusters (e.g. the Neuroscience Gateway).

tutorial_steps:
Download and install BRAINCELL from <a href="https://www.neuroalgebra.net/tools">neuroalgebra.net/tools</a> following the OS-specific instructions. Launch the application — it opens the main BRAINCELL interface which prompts you to choose a cell type (Neuron, Astrocyte, or Microglia) and an input file format (Base Geometry File, BrainCell Export, or Advanced HOC File).
Import a cell morphology: select SWC or NeuroML format and provide a local file or download from a database link. For neurons, the standard choice is a 3D-reconstructed CA1 pyramidal cell from NeuroMorpho.org. BRAINCELL parses the morphology and displays it in the 3D viewer with soma, dendrites, and axon colored by compartment type.
Populate dendrites with stochastic dendritic spines using the Manager of Spine Seeding: define the set of dendrites to seed, set the maximum spines per section, and choose a spine geometry distribution (uniform, normal, or empirically matched — the paper uses Tonnesen et al. STED statistics for CA1 spines). BRAINCELL generates the spine population stochastically and displays the result on the 3D cell.
Configure synaptic inputs via the Seed Synapses menu: specify the number, type (axo-dendritic or axo-spinous), presynaptic firing rate, release probability Pr, and spatial distribution (uniform, linear gradient, or Gaussian along apical dendrites). For extracellular ion dynamics, use the Extracellular Source interface to define a 3D sphere of elevated [K+]o with onset, duration, and concentration.
Run the simulation and inspect output: BRAINCELL generates membrane voltage heatmaps on the 3D cell, time-course traces, and input-output firing-frequency curves. For multi-cell configurations (neuron + astrocytes, or neuron + basket cell with GABA diffusion), use the Manager of Extra Cells to import and position additional cells, then configure cell-cell interactions via the extracellular diffusion and RxD settings. Use the built-in AI agent for natural-language modifications to MOD/HOC/Python files without editing code directly.

tutorial_output:
3D animated membrane voltage or ion concentration heatmaps; somatic voltage traces and spike rasters; input-output firing frequency curves; extracellular concentration time courses for ions and neurotransmitters; spatial snapshots of extracellular GABA, K+, or glutamate waves. Results can be exported as CSV/hoc files for further analysis or as figures directly from the GUI.
