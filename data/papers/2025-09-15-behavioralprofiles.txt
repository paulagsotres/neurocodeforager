summary:
A reusable behavioral analysis pipeline combining DeepLabCut (pose estimation), Keypoint-MoSeq (unsupervised syllable decomposition), and DeepOF (supervised trait extraction) to characterize conditioned behavioral responses in mice with two complementary arms: unsupervised (syllable Δ vectors, Hotelling's T², transition matrix Manhattan distances, Shannon entropy, Pearson correlations, MDS angle analysis) and supervised (radar plots with Intersection over Union). The pipeline detects age-dependent deficits in second-order conditioning that traditional freezing measures miss entirely.

abstract_long:
The paper introduces a data-driven behavioral analysis pipeline that chains three existing open-source tools into a unified framework for characterizing conditioned behavioral responses with far greater resolution than traditional single-metric approaches (e.g. freezing time). Applied to a light-tone second-order conditioning (SOC) paradigm in mice, the pipeline revealed that CS1 (first-order) and CS2 (second-order) stimuli elicit qualitatively distinct behavioral repertoires — not just scaled versions of each other — and detected age-related impairments in SOC responses that were completely invisible to huddling/freezing measures.

The unsupervised arm uses DeepLabCut for markerless pose estimation (14 body points, ResNet-50, 20 labeled frames per video) followed by Keypoint-MoSeq for decomposition of tracking data into behavioral syllables (discrete recurring motifs, 9 latent dimensions, kappa 1e10/1e4). For each animal and time bin, the pipeline computes Δ vectors (post-stimulus minus pre-stimulus syllable frame counts), tests the multivariate Δ distribution with Hotelling's T², assesses individual syllable changes with ANOVA/Kruskal-Wallis, builds normalized transition matrices, computes Manhattan distances between pre- and post-stimulus matrices (permutation-tested), and extracts Shannon entropy of transition probabilities to quantify behavioral stereotypy. To test whether CS1 and CS2 responses are scaled versions vs qualitatively distinct, it computes within-subject Pearson correlations between syllable Δ vectors (tested against null r=1) and applies MDS with Mahalanobis distance to track the angle α between CS1 and CS2 trajectories in behavioral space as dimensionality increases.

The supervised arm runs DeepOF on DLC tracking files to extract predefined traits (huddling, sniffing, wall climbing, speed, looking around), normalises them to 0–1, visualises as radar plots, and quantifies behavioral profile changes with Intersection over Union (IoU, permutation-tested). The discrepancy between supervised and unsupervised arms reveals the limits of trait-based approaches: DeepOF captures immobility well but misses escape, dodging, and head-bobbing behaviors that the syllable decomposition detects.

tutorial_intro:
The <a href="https://github.com/marccanela/BehavioralProfiles">BehavioralProfiles</a> repository provides the analysis scripts that run after pose tracking and syllable extraction are complete. DeepLabCut, Keypoint-MoSeq, and DeepOF must each be installed in separate conda environments because their dependencies conflict — do not try to install them together. The BehavioralProfiles scripts themselves can be run in any of these environments or a fresh one (they only require numpy, scipy, pandas, matplotlib, scikit-learn). The pipeline has two arms that can be run independently: unsupervised (syllable-based, steps 3–6) and supervised (trait-based, step 7).

tutorial_steps:
Install the three upstream tools in separate conda environments. For DeepLabCut follow the <a href="https://github.com/DeepLabCut/DeepLabCut">official installation guide</a> (GPU recommended for training but not required for inference). For Keypoint-MoSeq:
<code>conda create -n kpms python=3.10
conda activate kpms
pip install keypoint-moseq</code>
For DeepOF:
<code>conda create -n deepof python=3.10
conda activate deepof
pip install deepof</code>
Clone the analysis scripts:
<code>git clone https://github.com/marccanela/BehavioralProfiles</code>

Generate pose tracking files with DeepLabCut (in the DLC environment). Train a model on your videos — the paper used DLC 3.0, ResNet-50 backbone, 14 body points (nose, ears, neck, spine points, tail base — tail tip excluded due to low reliability), 20 labeled frames per video. Run inference on all videos:
<code>deeplabcut.analyze_videos(config_path, video_list, save_as_csv=True)</code>
This produces per-video h5 and CSV files with (x, y, likelihood) per keypoint per frame. Exclude tail keypoints from downstream analysis if tracking quality is low (likelihood threshold typically 0.6).

Extract behavioral syllables with Keypoint-MoSeq (in the kpms environment). Load the DLC output files and fit the ARHMM model. Key hyperparameters from the paper: <strong>9 latent dimensions</strong> (chosen to explain ~90% of variance in the dataset) and <strong>kappa values 1e10 and 1e4</strong>:
<code>import keypoint_moseq as kpms

# Load DLC data
coordinates, confidences = kpms.load_deeplabcut_results("path/to/dlc_outputs/")

# Fit model
model = kpms.fit_model(
    coordinates=coordinates,
    confidences=confidences,
    num_ar_iters=50,
    kappa=1e10,         # paper value
    num_states=9        # latent dimensions
)

# Extract syllable labels
syllables = kpms.get_syllable_labels(model)</code>
Save the syllable label sequences (per-frame integer) as CSV or pickle files — these are the input to the BehavioralProfiles analysis scripts. Keypoint-MoSeq orders syllables by frequency of occurrence (syllable 0 = most common).

Compute syllable abundance Δ vectors (unsupervised arm, step 1). Using the BehavioralProfiles scripts, divide each session into 1-min bins immediately before cue onset and during cue presentation (CS1 or CS2). Count frames per syllable per bin, then compute the Δ vector (post minus pre) per animal. The paper uses <strong>Hotelling's T²</strong> to test whether the multivariate Δ distribution differs from zero (null: syllable usage unchanged):
<code>from scipy.stats import chi2
import numpy as np

def hotellings_t2(delta_matrix):
    """delta_matrix: (n_animals x n_syllables)"""
    n, p = delta_matrix.shape
    mean_vec = delta_matrix.mean(axis=0)
    cov = np.cov(delta_matrix.T)
    T2 = n * mean_vec @ np.linalg.pinv(cov) @ mean_vec
    F = T2 * (n - p) / (p * (n - 1))
    p_val = 1 - chi2.cdf(T2, df=p)
    return T2, p_val</code>
For conditions showing overall significance, test individual syllables with one-way ANOVA or Kruskal-Wallis (choose based on Shapiro-Wilk normality), with Tukey HSD or Wilcoxon post-hoc and p-value correction across all syllables.

Compute transition dynamics (unsupervised arm, step 2). Build unidirectional transition matrices per animal per time bin (remove self-transitions, normalise by row-wise conditional probabilities). Quantify cue-induced changes as <strong>Manhattan distance (MD)</strong> between pre- and post-stimulus matrices, tested with permutation tests (shuffle pre/post labels within animals, 1000+ permutations):
<code>def manhattan_distance(mat_pre, mat_post):
    return np.sum(np.abs(mat_post - mat_pre))

def permutation_test_md(pre_mats, post_mats, n_perm=1000):
    obs_md = np.mean([manhattan_distance(p, q) for p, q in zip(pre_mats, post_mats)])
    null = []
    for _ in range(n_perm):
        shuffled = [manhattan_distance(*np.random.choice([p, q], 2, replace=False))
                    for p, q in zip(pre_mats, post_mats)]
        null.append(np.mean(shuffled))
    return obs_md, np.mean(np.array(null) >= obs_md)</code>
Compute <strong>Shannon entropy</strong> of the normalised transition matrices per animal per time point (higher entropy = more unpredictable transitions; decrease in entropy = behavior becomes more stereotyped):
<code>from scipy.stats import entropy as shannon_entropy
# For each row of the normalised transition matrix:
row_entropies = [shannon_entropy(row) for row in norm_matrix if row.sum() > 0]
mean_entropy = np.mean(row_entropies)</code>
Test entropy differences across time points with paired t-test or Wilcoxon signed-rank depending on Shapiro-Wilk normality.

Assess CS1 vs CS2 similarity (unsupervised arm, step 3). Compute within-subject <strong>Pearson correlations</strong> between syllable Δ vectors for CS1 and CS2 per animal. Test whether the mean correlation equals 1 (perfect similarity null) with a one-sample t-test and compute 95% confidence intervals. For a higher-dimensional view, apply <strong>MDS with Mahalanobis distance</strong> to syllable usage data across 2–10 embedding dimensions. Compute centroids for baseline, CS1, and CS2 behavioral states, then calculate the angle α between the baseline→CS1 and baseline→CS2 vectors:
<code>from sklearn.manifold import MDS
from scipy.spatial.distance import mahalanobis

def compute_angle(centroid_base, centroid_cs1, centroid_cs2):
    v1 = centroid_cs1 - centroid_base
    v2 = centroid_cs2 - centroid_base
    cos_a = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
    return np.degrees(np.arccos(np.clip(cos_a, -1, 1)))

for n_dims in range(2, 11):
    mds = MDS(n_components=n_dims, dissimilarity='precomputed')
    embedding = mds.fit_transform(mahalanobis_dist_matrix)
    angle = compute_angle(baseline_centroid, cs1_centroid, cs2_centroid)
    print(f"{n_dims} dims: alpha = {angle:.1f} degrees")</code>
Growing α with dimensionality (the paper finds ~30° → >70°) indicates CS1 and CS2 responses follow qualitatively distinct trajectories in behavioral space, not just scaled versions.

Extract supervised traits and build radar plots (supervised arm). Run <a href="https://github.com/mlfpm/deepof">DeepOF</a> on the DLC tracking files (in the deepof environment) to extract predefined behavioral traits:
<code>import deepof.data

project = deepof.data.Project(
    project_path="deepof_project/",
    video_path="videos/",
    table_path="dlc_outputs/",
    animal_ids=["mouse"]
)
project = project.create()
coords = project.get_coords(center="Center", align="Spine_1")
traits = project.supervised_annotation()</code>
Average trait values (huddling, sniffing, wall climbing, speed, looking around) within 1-min time bins and normalise to 0–1. Visualise as radar plots with active traits (speed, climbing, sniffing) on one side and passive traits (huddling, looking around) on the other. Quantify behavioral profile changes using <strong>Intersection over Union (IoU)</strong> between pre- and post-stimulus radar profiles, tested with permutation tests. A low IoU (e.g. 0.23 for CS1-paired) indicates a large behavioral shift; a high IoU (e.g. 0.76 for CS1-no-shock) indicates stability.
