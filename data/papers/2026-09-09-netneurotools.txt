summary:
netneurotools is a Python toolbox that fills the gap between large, specialized neuroimaging packages — offering modular, trainee-tested functions for the full network neuroscience workflow: fetching datasets and atlases, constructing consensus and surrogate networks, computing graph metrics and spatial statistics, running permutation tests, and visualizing results on brain surfaces. Developed organically by the Misic lab since 2017 and used across more than 15 publications.

abstract_long:
Modern network neuroscience projects typically involve many moving parts: importing brain atlases, parcellating brain maps, constructing consensus connectivity matrices, computing graph metrics, running spatially-informed statistical tests, and rendering results on brain surfaces. The "daylight" between major specialized packages — fMRIPrep, Nilearn, NetworkX, Brain Connectivity Toolbox — is substantial, and trainees are left to develop ad hoc scripts that rarely survive beyond one or two generations. netneurotools fills this gap with nine modules covering the full analytical lifecycle: datasets (programmatic download of atlases, templates, and published datasets), networks (consensus and surrogate network construction), metrics (graph-theoretic measures including communicability, navigation efficiency, and assortativity), modularity (consensus community detection via the Louvain algorithm), stats (correlation, permutation testing, regression, and dominance analysis), spatial (Moran's I, Geary's C, and Lee's L spatial autocorrelation), plotting (surface-based and parcellated brain visualization via PyVista/VTK), interface (parsers for FreeSurfer, CIFTI, and GIfTI formats), and experimental (sandbox for community contributions). BSD-3 licensed, continuously tested via GitHub Actions, and distributed via PyPI and Docker.

tutorial_intro:
netneurotools is installed via pip and works on any parcellated brain data — connectivity matrices, brain maps, or atlases. The typical workflow starts with the <code>datasets</code> module to fetch standard atlases or published datasets, then passes through <code>networks</code>, <code>metrics</code>/<code>modularity</code>, and <code>stats</code> for analysis, and ends with <code>plotting</code> for surface visualization. Modules are decoupled and can be used independently.

tutorial_steps:
Install via pip: <code>pip install netneurotools</code>. For the latest development version: <code>pip install git+https://github.com/netneurolab/netneurotools.git</code>.
Fetch a standard dataset or atlas using the <code>datasets</code> module — for example <code>nnt.datasets.fetch_schaefer2018()</code> returns a Schaefer parcellation, and published datasets from the lab's papers (myelin maps, connectivity matrices, receptor maps) can be fetched similarly with no manual downloading required.
Construct a consensus or surrogate network using the <code>networks</code> module. <code>nnt.networks.struct_consensus()</code> builds a group-representative structural connectivity matrix using distance-dependent thresholding; <code>nnt.networks.match_length_degree_distribution()</code> generates surrogate networks for null-model testing.
Compute graph-theoretic or communication metrics with the <code>metrics</code> module (e.g. <code>communicability_wei()</code>, <code>navigation_wu()</code>, <code>assortativity_und()</code>), or detect community structure with <code>nnt.modularity.consensus_modularity()</code>, which runs Louvain across multiple resolutions and derives a robust consensus partition.
Run statistical tests with the <code>stats</code> module — <code>permtest_pearsonr()</code> for spin-test-corrected correlations between brain maps, <code>get_dominance_stats()</code> for per-predictor variance decomposition in multiple regression — or spatial autocorrelation with <code>nnt.spatial.morans_i()</code>.
Visualize results on the brain surface with <code>nnt.plotting.pv_plot_parcellated_data()</code> (parcellated values on a cortical surface mesh, customizable views and colormaps) or <code>nnt.plotting.plot_mod_heatmap()</code> for community-ordered connectivity heatmaps.

tutorial_output:
Depending on which modules you use: consensus connectivity matrices, surrogate network ensembles, graph metrics per node or edge, community assignments, permutation p-values, dominance statistics, spatial autocorrelation coefficients, or rendered brain surface figures — all as standard Python objects (numpy arrays, pandas DataFrames) or saved figures.
