summary:
This paper introduces a multilevel Bayesian hidden Markov model (mHMMbayes) for longitudinal multi-electrode spiking data, using a multivariate Poisson log-normal emission distribution and trial-specific random effects so that hidden neural population states — and their relationship to behavior — generalize consistently across multiple days of recording, unlike a standard single-level HMM which failed to generalize across sessions in the same dataset.

abstract_long:
Chronically implanted multi-electrode arrays let researchers record from the same neural population over weeks or months, but standard hidden Markov model (HMM) approaches to segmenting this activity into discrete population states assume the same transition and emission parameters apply to every trial — ignoring the nested, trial-by-trial and day-by-day structure of longitudinal recordings. The authors' multilevel Bayesian HMM instead estimates trial-specific transition and emission parameters (centered around group-level means) via a multivariate Poisson log-normal emission distribution suited to multi-electrode spike-count data, fit with an iterative Bayesian (Gibbs-based) estimation procedure rather than classic expectation-maximization. Applied to macaque primary motor cortex activity recorded across 10 days during a reaching-grasping-placing task, the model identified five-to-six discrete population states whose onset/offset times were tightly and stably linked to behavioral events (movement onset, object contact, placing) across the entire recording period — a relationship a comparison single-level HMM could not reliably recover, since it lacks trial-specific parameters and so cannot generalize the same state definitions across sessions recorded on different days.

tutorial_intro:
mHMMbayes expects binned spike counts (the paper used 10 ms bins) per electrode, per trial, optionally alongside trial-level covariates (such as experimental condition) that you want the transition probabilities to depend on. It's not yet on CRAN — the multilevel Poisson log-normal functionality used in this paper lives on the package's "develop" branch.

tutorial_steps:
Install the development version directly from GitHub, e.g. <code>remotes::install_github("smildiner/mHMMbayes", ref = "develop")</code>, to get the <code>HMM_plnorm</code> (single-level) and <code>mHMM_plnorm</code> (multilevel) functions used in this paper.
Prepare your data as binned spike counts per electrode and trial, plus any trial-level covariates you want to include in the transition model.
Fit the model, specifying the number of hidden states, starting values for the group-level transition and emission parameters (a conventional EM-fit single-level HMM — for example via the depmixS4 package — is a convenient source for these starting values), and non-informative hyper-priors for the group-level parameters.
Select the number of states by comparing relative fit (AIC/BIC) across several candidate values, and confirm convergence of all group-level parameters using the multivariate potential scale reduction factor (target Ȓ below 1.05) across at least two additional chains with randomized starting values.
Validate the fitted model with Bayesian posterior predictive checks: simulate new datasets from the fitted model and compare summary statistics (mean, standard deviation, maximum counts, proportion of zeros) against your real data, aggregated across trials per electrode.
Decode the most likely hidden-state sequence for each trial using the Viterbi algorithm with that trial's own estimated trial-specific parameters — this trial-specific decoding (rather than one shared parameter set for every trial) is the paper's key advantage over a standard single-level HMM for longitudinal data.
Relate the decoded state onset/offset times and state statistics (number of activations per trial, state lifetime) to your own behavioral event timings using your own correlation or regression approach — the package provides the fitted states and their forward probabilities, and downstream behavioral analysis is left to the user (the paper's own such analysis code is a separate repository — see the link above).

tutorial_output:
A fitted multilevel HMM with group-level and trial-specific estimates of the transition probability matrix and the Poisson log-normal emission means per electrode and state (each with credibility intervals), plus, via the Viterbi algorithm, a decoded most-likely hidden-state sequence for every trial — from which state onset/offset times, activation counts, and lifetimes can be computed and related to behavioral events or experimental conditions.
